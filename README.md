# PACT Audioguide — versione iniziale

Questa cartella contiene la prima struttura pubblicabile su GitHub Pages.

## Caricamento su GitHub

1. Estrai il file ZIP sul computer.
2. Nella pagina “Upload files” di GitHub, trascina **il contenuto della cartella**:
   - `index.html`
   - cartella `assets`
   - `README.md`
3. Premi **Commit changes**.
4. Nel repository apri **Settings → Pages**.
5. In “Build and deployment”, scegli:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Premi Save.

## Audio

Gli audio vanno inseriti con questa struttura:

- `assets/audio/banditaccia/it/01.mp3`
- `assets/audio/banditaccia/en/01.mp3`
- `assets/audio/banditaccia/fr/01.mp3`
- `assets/audio/monterozzi/it/01.mp3`
- `assets/audio/monterozzi/en/01.mp3`
- `assets/audio/monterozzi/fr/01.mp3`
- `assets/audio/regno-ombre/it/01.mp3`
- `assets/audio/regno-ombre/en/01.mp3`

La numerazione continua con `02.mp3`, `03.mp3` e così via.

## Loghi ufficiali

La cartella `assets/logos` è pronta per ricevere i file ufficiali autorizzati del MiC e del PACT.
La versione iniziale usa un marchio tipografico provvisorio “PA”, così non vengono distribuiti
loghi istituzionali senza avere i file originali e l’autorizzazione interna corretta.
