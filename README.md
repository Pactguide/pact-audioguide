# PACT Audioguide – Pacchetto 2 completo

Questo pacchetto contiene grafica, immagini, database e tutti gli audio disponibili collegati alle rispettive tappe.

## Uso
Caricare l’intero contenuto del pacchetto nella radice del repository GitHub Pages, mantenendo identiche cartelle e nomi dei file.

## QR code
- Necropoli: un QR per ciascun percorso, diretto all’elenco delle tappe.
- Mostra: un QR per ciascuna traccia, diretto alla singola pagina.

Gli indirizzi definitivi dei QR saranno generati dopo la pubblicazione su GitHub Pages, quando sarà noto l’URL pubblico del sito.
